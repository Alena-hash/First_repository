# Проект автоматизации тестирования (Lesson 10)

Данный проект содержит автотесты для интернет-магазина **SauceDemo** и страницы **Slow Calculator**. Тесты реализованы с использованием паттерна **Page Object** и интегрированы с системой отчетности **Allure**.

## Предварительные требования

Для запуска проекта и просмотра отчетов вам понадобятся:
1. **Python 3.x**
2. **Java** (необходима для работы Allure CLI)
3. Установленные зависимости из файла `requirements.txt`:
   ```bash
   pip install pytest selenium allure-pytest
